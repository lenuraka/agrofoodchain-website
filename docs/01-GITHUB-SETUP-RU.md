# Инструкция: GitHub для AGRO FOOD CHAIN

## 1. Создайте репозиторий
1. Зарегистрируйтесь на https://github.com/ или войдите в учётную запись.
2. Откройте https://github.com/new .
3. Repository name: `agrofoodchain-website`.
4. Description: `AGRO FOOD CHAIN | International Auditing, Certification Support & Consulting`.
5. Visibility: **Private**.
6. Нажмите **Create repository**. Если будете загружать готовую структуру, не обязательно создавать автоматический README.

## 2. Загрузите структуру сайта
1. Скачайте `agrofoodchain-github-starter.zip` и **распакуйте** его.
2. В репозитории нажмите **Add file → Upload files**.
3. Перетащите файлы и папки **изнутри распакованной папки**: `README.md`, `.gitignore`, `theme`, `content`, `docs`, `preview`. При загрузке через браузер можно перетащить папки или использовать GitHub Desktop, если браузер не позволяет выбрать каталог.
4. Комментарий к сохранению: `Initial website structure and WordPress theme`.
5. Нажмите **Commit changes** (или предложенную GitHub кнопку сохранения).
6. Откройте `README.md` в репозитории: это инструкция для разработчика.

**Важно:** Если загрузить ZIP в репозиторий без распаковки, GitHub сохранит его как один файл, а не создаст структуру каталогов.

## 3. Как работать с разработчиком
- В репозитории откройте **Settings → Collaborators and teams** (или **Collaborators**).
- Предоставьте доступ по приглашению с минимальными необходимыми правами.
- Рекомендуемый процесс: новая задача → отдельная ветка → Pull Request → просмотр изменений → Merge.
- Главную ветку `main` желательно защитить от нерассмотренных изменений.
- Никому не передавайте пароль от GitHub; включите двухфакторную аутентификацию.

## 4. Что хранить в GitHub
**Можно:** исходный код WordPress-темы, статические стили, скрипты, шаблоны, тексты без конфиденциальных данных, инструкции.

**Нельзя:** пароли, API-ключи, `wp-config.php`, выгрузки персональных данных, базы клиентов, отчёты по аудитам с коммерческой тайной, реальные данные форм заявки.

## 5. Где будет работать сайт
GitHub = управление исходным кодом, **не** рабочий сервер WordPress.
WordPress размещается у европейского хостинг-провайдера с PHP, MySQL/MariaDB, HTTPS, резервным копированием и обновлениями безопасности.

## 6. Контроль версий
Каждое изменение сохраняется как **commit**. Для крупного изменения используйте отдельную ветку (branch); после проверки объединяйте в основную (merge). Возможность отката — одно из главных преимуществ GitHub.
