# Перенос дизайна из чата «Гранты и проекты Узбекистана»

**Референс:** 27.10.2026, выбран первый зелёно-золотой вариант.

**Перенесено:** фирменная эмблема SVG из ранее подготовленной темы v1.1, цветовая схема, корпоративная типографика, верхняя узкая строка, белая шапка с CTA, главное фото на весь экран, две основные кнопки, шесть фото-плиток отраслей, восемь направлений услуг, блок международных партнёров, регионы Центральной Азии.

**Отличия от дизайн-борда:** макет в бренд-борде являлся визуальной концепцией без работающего кода; использованы адаптивные компоненты, CSS и семантические элементы. Временные фото-плитки взяты из дизайн-макета, главный пейзаж включает локальный SVG-фолбэк и внешнее фото Unsplash. Не публикуются неподтверждённые метрики 100+ и 20+.
