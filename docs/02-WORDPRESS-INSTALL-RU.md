# WordPress: установка темы и контента

## Минимальные предпосылки
- Домен и работающий WordPress на хостинге, отвечающем актуальным требованиям WordPress.
- HTTPS, автоматические бэкапы, администраторская 2FA, ограничение доступа, обновления.
- Европейский сервер возможен, но конкретный хостинг и домен здесь **не заказаны**.

## Установка темы
1. В админ-панели WordPress: **Внешний вид → Темы → Добавить новую → Загрузить тему**.
2. Выберите отдельный файл `agrofoodchain-theme.zip`.
3. Нажмите **Установить**, затем **Активировать**.
4. Если делаете установку вручную, скопируйте `theme/agrofoodchain` в `wp-content/themes/`.

## Импорт страниц
1. В WordPress перейдите **Инструменты → Импорт → WordPress**.
2. При необходимости установите и активируйте плагин WordPress Importer.
3. Импортируйте `content/wordpress-import.xml`.
4. Перейдите **Настройки → Чтение → Статическая главная страница**.
5. Выберите `Home` как главную страницу, `Insights` — как страницу записей.
6. Откройте **Настройки → Постоянные ссылки** и выберите «Название записи».
7. Настройте меню через **Внешний вид → Меню**, назначив область Primary.
8. Проверьте, что ссылки `/services/`, `/supplier-audits/`, `/contact/` открываются.

## Настройка компании
- **Внешний вид → Настроить → Контактные данные компании**: добавьте публичные email и телефон.
- **Внешний вид → Настроить → Свойства сайта**: загрузите одобренный логотип. Сейчас в теме временный типографический знак.
- Установите плагин контактной формы, подключите SMTP/доставку почты, капчу/антиспам и дайте информацию о конфиденциальности.
- Добавьте реальное подтверждённое юридическое наименование, адрес и реквизиты после согласования.
- Установите надёжный SEO-плагин, задайте title/description по `content/seo-plan.csv`, карту сайта и canonical URL.
- Для русского/узбекского языков выберите мультиязычный плагин, проверьте `hreflang`, переводы и структуру URL.

## Проверка перед публикацией
- Проверить мобильную версию, меню, формы, ссылки, тексты, заявления о партнёрстве и сертификатах.
- Временно закрыть индексацию тестового сайта, снять ограничение только после проверки.
- Добавить политику конфиденциальности и уведомление о cookies, учитывая реальные способы обработки данных.

**Обратите внимание:** основной ZIP проекта для GitHub и ZIP темы для WordPress — это **разные** архивы.
