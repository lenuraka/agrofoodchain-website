# Исходные презентации для автоматического импорта

В этот каталог должны быть помещены **14 оригинальных PPTX**, по одному на каждый раздел ISO 22002-2:2025, с номерами **Раздел_04** … **Раздел_17** в именах файлов.

Например:

- `ISO_22002-2_2025_Раздел_04_Конструкция-и-планировка(1).pptx`
- `ISO_22002-2_2025_Раздел_05_Планировка-помещений-и(1).pptx`
- …
- `ISO_22002-2_2025_Раздел_17_Приготовление-и-выдача(1).pptx`

**Каждая презентация должна содержать 6 слайдов.** Автоматический импорт использует только **слайды 1–5**, а шестой исключает.

После сохранения оригинальных презентаций GitHub Actions выполняет:

1. Конвертацию страниц 1–5 в PNG с фотографиями и оформлением;
2. Создание `assets/slides/04_01.png` … `17_05.png` (70 файлов);
3. Извлечение комментариев диктора в `assets/content/notes.json`;
4. Коммит новых графических файлов в эту же ветку (если GitHub Actions имеет право записи);
5. Сборку Windows и Android приложения с включёнными картинками.

Исходные PPTX и слайды содержат фотоиллюстрации. **Репозиторий является публичным**; не загружайте сюда конфиденциальные материалы предприятия.

Если исходные презентации не загружены, приложение использует точный текст и заметки из уже опубликованного `assets/content/original_slides.json`, без фотографий.

Форматирование и фотографии не восстановить из текстового файла: для полного импорта нужны сами PPTX.
