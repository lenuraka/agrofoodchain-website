# AGRO FOOD CHAIN Training — Flutter v2 (групповой режим)

Рабочий **исходный проект** приложения для Windows, Android и iOS на Flutter.
Он создан как новая ветка, без изменения действующего сайта и установленной версии Windows v1.9.

## Реализованная логика
- 14 разделов ISO 22002-2:2025, **5 учебных слайдов на раздел** (всего 70); шестые слайды исходных презентаций намеренно исключены.
- 300 заданий: 280 вопросов по 70 контрольным ситуациям в четырёх форматах и 20 дополнительных ситуационных вопросов. Для коммерческой аттестации рекомендуется предметная экспертная вычитка всех 300 формулировок.
- Итоговый экзамен: 20 случайных вопросов, 4 варианта на каждый, **зачёт от 16 правильных (80%)**.
- Новая выборка вопросов и новый порядок ответов при каждой попытке. Второй ответ получает верное решение статистически чаще: вероятность 40%; остальные позиции — по 20%. Проверка основана на исходном правильном варианте, а не его букве.
- Учебные группы: название, предприятие, список сотрудников; общий просмотр курса, затем отдельный экзамен **по выбранным Ф.И.О.** каждого сотрудника.
- SQLite на устройстве: история результатов, дата, группа, участник, ответы, количество верных; повторные попытки и экспорт CSV.
- Учебные материалы работают офлайн после импорта изображений и MP3.

## Что нужно для полного использования исходных презентаций
Графические файлы слайдов и записанные голоса **не выложены в публичный GitHub**; это материалы заказчика. В приложении есть текстовая резервная версия уроков. Чтобы использовать реальные презентации:
1. Установите Python 3.11+, Microsoft PowerPoint или LibreOffice.
2. Положите 14 PPTX (разделы 04–17) в одну папку, например C:\AFC\source_pptx.
3. Выполните из папки проекта:
   `python -m pip install -r tools/requirements-import.txt`
   `python tools/import_pptx.py "C:\AFC\source_pptx"`
4. Получатся `assets/slides/04_01.png` … `17_05.png`, точно по 5 первых слайдов, без шестого; тексты заметок сохранятся в `assets/content/notes.json`.
5. Для записи MP3 при наличии интернета можно добавить `--audio` (голос по умолчанию Microsoft Svetlana Neural). До коммерческого использования синтеза проверьте условия лицензирования; для высокого качества предпочтительны заранее утверждённые записи диктора.
6. После импорта пересоберите приложение командой `flutter build windows` или `flutter build apk`.

## Windows: сборка
Установите Flutter SDK и Visual Studio с компонентом «Desktop development with C++».
```powershell
cd apps\afc-training
flutter create --project-name afc_training --platforms=windows .
python tools/get_font.py
flutter pub get
flutter test
flutter run -d windows
flutter build windows --release
```
Готовую папку Windows-приложения ищите в `build/windows/x64/runner/Release/`; **переносите всю папку**.
В ветке GitHub предусмотрен CI для сборки и скачивания Windows-артефакта.

## Android / iOS
Android: `flutter create --platforms=android .`, затем `flutter build apk --debug` для тестирования.
iOS: сборка на macOS с Xcode и Apple Developer, `flutter create --platforms=ios .`.
Собранные приложения должны пройти испытания на реальных устройствах.

## Сценарий группового обучения
1. Администратор создаёт группу и указывает предприятие.
2. Вносит фамилии и имена участников.
3. Выбирает «Совместный просмотр» и демонстрирует материалы группе; аудиодорожки включаются через «Озвучка».
4. После 70-го слайда подтверждает завершение группового просмотра.
5. Выбирает участника — программа ещё раз просит подтвердить Ф.И.О.
6. Слушатель отвечает на 20 вопросов, получает индивидуальный результат.
7. Следующий сотрудник выбирает своё имя и сдаёт новый случайный вариант экзамена.
8. Администратор экспортирует результаты в CSV.

## Ограничения и безопасность
- Выбор имени без удостоверения личности недостаточен для дистанционного подтверждения личности. Для коммерческой выдачи именных сертификатов необходимо добавить PIN участника либо контроль ответственным лицом.
- После результата от 80% формируется PDF-сертификат без графического логотипа и водяного знака, сохраняемый в служебной папке приложения. Перед сборкой требуется `python tools/get_font.py` (загрузка Unicode-шрифта для офлайн-работы). Прямая SMTP-отправка из предыдущих прототипов пока не перенесена; она требует защиты учётных данных и тестирования.
- Старую SQLite-базу v1.9 этот проект автоматически не импортирует.
- Само наличие 300 вопросов не означает валидацию всех вопросов как официальных вопросов ISO; это учебные сценарии, основанные на предоставленных 14 презентациях.
- Без импорта собственных PPTX/MP3 экран курса показывает текстовые примеры, а кнопка «Озвучка» сообщает об отсутствии файла.
- Проект содержит исходный код, не готовый установщик. GitHub CI выполняет компиляцию после открытия PR; итог сборки необходимо проверить.

Все тексты и демонстрационные материалы — учебная адаптация, а не полный текст стандарта и не аккредитованная сертификация.
